# Week 3 - Machine Learning Model

## Objective
Develop a machine learning model using the cleaned agricultural dataset to predict crop yield.

## Machine Learning Task
Regression

## Algorithm
Random Forest Regression

## Dataset
The cleaned dataset contains 19,689 records.

## Train-Test Split
- Training data: 80%
- Testing data: 20%

## Evaluation
- MAE: 7.5773
- RMSE: 103.1508
- R² Score: 0.9867

## Conclusion
A Random Forest Regression model was developed to predict crop yield using agricultural and environmental features. The model achieved an R² score of 0.9867 on the test dataset.
