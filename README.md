# Agribusiness Data Collection and Cleaning

## Internship – Week 1

This project focuses on collecting, cleaning, preprocessing, and statistically analyzing a publicly available agribusiness dataset.

### Objective
- Collect a publicly available dataset related to agribusiness.
- Inspect and assess data quality.
- Handle missing values, duplicates, inconsistent data, and outliers where appropriate.
- Apply preprocessing and normalization when necessary.
- Produce a cleaned dataset and statistical summary.
- Document the complete data-cleaning process and challenges encountered.
